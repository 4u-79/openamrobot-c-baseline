# Run Instructions

From the repo root (`scripts/run_dashboard.py` lives in `scripts/`):

```bash
python scripts/run_dashboard.py
# → open http://127.0.0.1:8300
```

### Common variants:

```bash
python scripts/run_dashboard.py --open                       # auto-open browser
python scripts/run_dashboard.py --port 9000                  # different port
python scripts/run_dashboard.py --report reports/qa_report.json   # explicit report
```
